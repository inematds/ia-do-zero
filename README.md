**Os primeiros 20 pedidos de quem nunca usou IA**, organizados por situação do dia a dia, com o que você deve ver na resposta e o erro comum de cada um. Mais 10 dicas práticas. Funciona em qualquer chat de IA, inclusive nas versões gratuitas.

## 📖 Guia de uso

Página completa (kit + dicas + exemplos): **https://inematds.github.io/ia-do-zero/guia/**

## O que tem

- **A · Escrever**: e-mail difícil, mensagem para cliente, comunicado, melhorar um rascunho.
- **B · Entender**: resumir documento longo, explicar cláusula, traduzir algo técnico para o cliente.
- **C · Organizar**: planilha do zero, semana a partir de uma lista bagunçada, pauta de reunião com decisão.
- **D · Decidir**: comparar duas opções, as perguntas antes de fechar, conferir um número antes de repassar.
- **E · Atender e vender**: responder reclamação, descrever um serviço, post sobre uma novidade.
- **F · Pedir melhor**: fazer a IA perguntar antes, aprender do zero em 15 minutos, três versões, corrigir o tom.

Cada pedido tem quatro partes fixas: quando usar · o pedido colável (o que está entre `< >` você troca) · o que você deve ver · o erro comum.
