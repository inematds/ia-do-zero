Página completa (kit + consejos + ejemplos): **https://inematds.github.io/ia-do-zero/guia/es/**

## Qué incluye

- **A · Escribir**: correo electrónico difícil, mensaje para un cliente, comunicado, mejorar un borrador.
- **B · Entender**: resumir un documento largo, explicar una cláusula, traducir algo técnico para el cliente.
- **C · Organizar**: hoja de cálculo desde cero, semana a partir de una lista desordenada, agenda de reunión con una decisión.
- **D · Decidir**: comparar dos opciones, las preguntas antes de cerrar, verificar un número antes de compartirlo.
- **E · Atender y vender**: responder a una queja, describir un servicio, publicación sobre una novedad.
- **F · Pedir mejor**: hacer que la IA pregunte antes, aprender desde cero en 15 minutos, tres versiones, corregir el tono.

Cada pedido tiene cuatro partes fijas: cuándo usarlo · el pedido listo para copiar y pegar (lo que está entre `< >` lo reemplazas) · lo que deberías ver · el error común.
