# 🌱 IA from Scratch

**🇧🇷 [Português](README.md) · 🇺🇸 [English](README.en.md) · 🇪🇸 [Español](README.es.md)**

**The first 20 prompts for people who have never used AI**, organized by everyday situation, with what to expect in the response and the common mistake for each one. Plus 10 practical tips. Works in any AI chat, including free versions.

## 📖 User guide

Full page (kit + tips + examples): **https://inematds.github.io/ia-do-zero/guia/en/**

## What’s included

- **A · Write**: difficult email, message to a client, announcement, improve a draft.
- **B · Understand**: summarize a long document, explain a clause, translate something technical for a client.
- **C · Organize**: spreadsheet from scratch, plan a week from a messy list, meeting agenda with a decision.
- **D · Decide**: compare two options, questions to ask before committing, check a number before passing it along.
- **E · Serve and sell**: respond to a complaint, describe a service, post about something new.
- **F · Ask better**: have AI ask questions first, learn from scratch in 15 minutes, three versions, adjust the tone.

Each prompt has four fixed parts: when to use it · the copy-and-paste prompt (replace what’s between `< >`) · what to expect · the common mistake.
